## Steam

| 확인 항목 | 상태 | 내용 |
|---|---|---|
| 공식 리뷰 API | ✅ | `GET api.steampowered.com/IUserReviewsService/GetAppReviews/v1/` 키 없이 호출 가능. 구형 `appreviews`는 지원 중단 공지 |
| 필드 | ✅ | 본문 · 추천 여부 · 작성 시각 · 언어 · 플레이 시간 · 개발자 답변 · 도움됨 수. 별점 · 앱 버전 · 국가 없음 |
| 기간 · 쪽 넘김 | ✅ | `date_range_start/end`, Recent 정렬 + cursor로 끝까지. 한 쪽 100건 |
| 이용 조건 | ✅ | Steam Web API ToU(2010-07): 하루 10만 회, Valve 제휴 오인 금지, 저장 데이터 고지. 원문 재배포 조항은 없어 보수적으로 발췌만 표시 |
| 리뷰 폭탄 필터 | ✅ | 기본값이 off-topic 리뷰 제외. 그대로 사용하고 문서에 표시 |
| 공식 뉴스 API | ✅ | `ISteamNews/GetNewsForApp/v2` 최근 90일 49건 |
