# 커뮤니티 정성 메모 작성 규칙 (아카라이브 · 디시)

결정: 2026-11-08 사용자. 자동 수집 대신 **사람이 직접 읽고 쓰는 정성 메모**. 숫자 분석(감성 비율 · 우선순위 점수)에는 넣지 않고 "커뮤니티 정성 관찰"로 따로 표시한다.

## 왜 이렇게 하나
- 한국 이용자 반응이 Steam 한국어 리뷰에 거의 없다(가챠 개편 불만 2/207). 11/10 한국 · 글로벌 모집 개편 반응을 볼 곳은 커뮤니티뿐이다.
- 디시인사이드 약관은 서면 동의 없는 크롤링을 목적과 상관없이 금지한다. 아카라이브는 약관 미확인. 그래서 자동 수집 · Claude 브라우저 대행을 하지 않는다.

## 기록 파일
`data/raw/community_notes/community_notes_kr.csv`

| 열 | 쓰는 법 |
|---|---|
| note_id | `arca_001` · `dc_001` |
| site / board | arcalive · dcinside / 채널 · 갤러리 이름 |
| post_url | 글 주소 |
| post_date | 글 작성일 YYYY-MM-DD |
| observed_at | 내가 읽은 날 YYYY-MM-DD |
| selection_rule | 고른 기준 (예: 개념글 목록 위에서부터, 추천순 상위) |
| window | pre (10/27 ~ 11/9) · post (11/10 ~ 11/23). 둘 다 화 ~ 월 주 단위 2주, 11/10 적용일은 post 첫날 (2026-11-15 사용자 결정) |
| topic | category_dictionary.csv 키 (monetization 등) |
| stance | 반발 / 옹호 / 중립 / 혼합 |
| my_summary | **내 말로 쓴 요약 60자 이내. 원문 문장 복사 금지** |
| visible_recommend | 화면에 보이는 추천 수(없으면 빈 칸) |
| labeler / note | 작성자 / 메모 |

## 규칙
1. 기간마다(pre · post) 20~30건. 고르는 기준을 먼저 정하고 바꾸지 않는다(내 생각과 맞는 글만 고르지 않기).
2. 원문 복사 · 캡처 저장 금지. 닉네임 · 작성자 정보 기록 금지.
3. 욕설 · 밈은 뜻만 요약한다.
4. 결과는 "커뮤니티에서 이런 반응이 관찰됨"으로만 쓴다. 비율 · 대표성 주장 금지.
5. 아카라이브는 이용약관을 직접 확인한 뒤 시작한다. 금지 조항이 있으면 아카라이브는 빼고 기록한다.
